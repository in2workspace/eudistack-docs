# Wallet — EUDIW

EUDIW (European Digital Identity Wallet) is the **personal** wallet of EUDIStack. Cryptographic keys and credentials are generated and stored **on the device** (*Browser* mode), protected by passkey / biometrics.

!!! tip "How do I know I am using EUDIW?"
    Open **Settings**. The **Wallet type** field shows the active mode: `EUDIW` corresponds to the personal wallet and `Business Wallet` to the organisational one.

    ![Wallet type field in Settings](../../assets/img/users/wallet-eudiw/type-wallet.png){ width="320" }
