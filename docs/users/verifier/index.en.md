# Verifier

The EUDIStack Verifier allows you to **verify credentials** presented by users (customers, third-party employees, visitors). There are two modes:

<div class="grid cards" markdown>

-   :material-monitor: [**Remote verification**](remote-verification.md)

    The user presents the credential from their wallet via a browser (web or app), for example during an online onboarding process.

-   :material-cellphone-link: [**Proximity verification**](proximity-verification.md)

    The verifier connects to the user's wallet by proximity (QR), for example at a physical access control point.

</div>

!!! eudistack "M2M also available"
    In addition to the H2M flows described here, EUDIStack supports machine-to-machine (M2M) verification for backend integrations.
