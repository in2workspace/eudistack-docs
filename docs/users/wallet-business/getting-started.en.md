# Getting started — Business Wallet

First-time activation of the Business Wallet: verifying the corporate email, creating the passkey (fingerprint, facial recognition or PIN) and confirming access.

---

## Requirements

- Corporate email address.
- Modern browser (Chrome, Edge, Safari, up-to-date Firefox).
- Internet connection.

---

## Steps

??? "1. Access the Business Wallet"
    Navigate to the organization's wallet URL.

??? "2. Enter the corporate email"
    The wallet asks for an email address to start the sign-up.

    ![Registration screen — entering the corporate email](../../assets/img/users/wallet-buisiness/wallet-register.png){ width="240" }

??? "3. Verify the OTP code <small>*(One-Time Password)*</small>"
    The system sends a 6-digit code to the email provided. Enter the code in the wallet to confirm your identity and complete the account sign-up.

    <figure markdown style="margin-left: 0;">
      ![Verification email with 6-digit OTP code](../../assets/img/users/wallet-buisiness/email-code.png){ width="400" }
      <figcaption> email - with 6-digit code</figcaption>
    </figure>
    
    ![Verification screen — entering the OTP code in the wallet](../../assets/img/users/wallet-buisiness/wallet-code-input.png){ width="240" }

??? "4. Create the passkey"
    The wallet asks you to register a passkey with the device's fingerprint, facial recognition or PIN. The passkey links the device to the account and enables future access without repeating the OTP <small>*(One-Time Password)*</small> process.

    ![Passkey creation screen](../../assets/img/users/wallet-buisiness/create-passkey.png){ width="240" }

??? "5. Access confirmed"
    You can now receive and present credentials from the Business Wallet.

    ![Business Wallet access confirmation screen](../../assets/img/users/wallet-buisiness/access-confirmation.png){ width="240" }
